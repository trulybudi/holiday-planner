# General Application Plan

## Baseline Goals
Every application must include:
- User Authentication (register, login, logout, password reset)
- User Profile (basic info, settings)
- CRUD Operations (create, read, update, delete data)
- Database Integration (schema + migrations generated by AI)
- UI Components (forms, buttons, navigation, responsive layout)
- Error Handling (validation, user-friendly messages)
- Testing (unit + integration tests for critical flows)
- Deployment instructions (Netlify/Vercel or equivalent)

## App-Specific Goals
- Defined per project in specialized plan.md
- AI generates schema, features, and workflows based on project name and description

## Checklist
- [ ] Authentication implemented
- [ ] CRUD implemented
- [ ] Database schema created
- [ ] UI components functional
- [ ] Error handling complete
- [ ] Tests written and passing
- [ ] Deployment instructions ready
