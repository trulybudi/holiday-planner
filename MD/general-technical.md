# General Technical Specification

## Stack
- Framework: Next.js
- Styling: TailwindCSS
- Database: Supabase (schema generated by AI)
- Auth: Supabase Auth (or NextAuth.js if required)
- Deployment: Netlify

## Rules
- Use modular repo structure
- Follow naming conventions (camelCase for variables, PascalCase for components)
- All API calls must use Supabase client or defined backend API
- No dummy implementations — AI must reference working code from reference.md
- Database schema must be generated as SQL migrations during build

## Environment Variables
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
GROQ_API_KEY=your_groq_api_key

## Boundaries
- External account creation (Supabase, Groq, etc.) is manual
- AI prepares queries and env placeholders only
- User inserts actual values manually
